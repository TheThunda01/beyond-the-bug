# Source of the example

`glass-participation.csv` transcribes two country counts from WHO’s description of GLASS participation. The unit is a country reporting to GLASS in the specified year. The source gives the endpoints of the comparison. No intermediate observations are supplied here.

WHO published the values on 13 October 2025. See the paragraph beginning “Country participation in GLASS” in the [WHO release](https://www.who.int/news/item/13-10-2025-who-warns-of-widespread-resistance-to-common-antibiotics-worldwide). For WHO publication reuse terms, see [WHO copyright and licensing](https://www.who.int/about/policies/publishing/copyright).

The book’s figure is drawn from the transcribed values using the Python standard library. No WHO artwork or manuscript text is reproduced.
